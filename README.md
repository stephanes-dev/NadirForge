# NadirForge

Provides a flexible framework for managing and tracking multiple versions of code across different branches and repositories.

NadirForge is built to be simple and practical, focusing on doing one thing well.

**Why NadirForge?**

- Provides a flexible framework for

- of code across different branches

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/NadirForge.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

NadirForge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
